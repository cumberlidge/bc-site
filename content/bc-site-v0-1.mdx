Infrastructure build out by setting up Vercel, GitHub and Visual Code Studio. Build from laptop to internet on my custom domain takes around 90 seconds.

- Domain registered. Deploys run automatically on push.
- Repository public, so the build log can link to it. Drafts stay out of git entirely — git keeps a file in history after deletion, so anything committed is public permanently.
- Chose a list layout over a tiled grid inspired by Experimental Jetset. 
- Killed a release-notes page before building it. Version numbers in these titles do the same job.
- Node 25 was installed — an odd-numbered line, never supported long-term, already past end of life. Switched to 24.
