Header added. Rest of the session was adjustment, mostly undoing the note treatment — specced as distinct, rendered wrong. A note is a shorter entry, not a different kind of page.

- Header on every page, name linking home. Description on the index only.
- Notes take an optional title. Narrow centred treatment gone, along with the permalink.
- Index and entry pages share one container width and one left edge. Index was running near-full-width.
- Index titles down to 18px, body text up to 19px. The list was competing with the reading.
- Italics removed throughout.
- Link colour dropped. Underline on hover and focus instead.
- Project metadata reduced to one line under the date.
- Dates display as 11 September 2026, ISO kept in the markup.
- Favicon.
